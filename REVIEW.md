# Проверка текущей версии — 16 ноября 2026

После замечания пользователя композиция заново построена по приложенному референсу. Предыдущая версия передавала только палитру и типографику; текущая повторяет расположение и пропорции основных блоков.

- Первый экран: тёмный Portfolio во всю ширину, крупный погрудный портрет поверх, UX/UI/WEB слева, Developer справа с контурной частью надписи.
- Далее: компактные парные блоки об авторе и шести этапах работы. Основной персонаж в полный рост сохранён в блоке об авторе.
- Витрина: три учебных проекта с настоящими скриншотами десктопной и мобильной версии. Четвёртый блок описывает услуги. Превью открывают интерактивный макет в диалоге.
- Нижний блок: «Сотрудничество», текст и форма слева, крупный круглый портрет справа. На телефоне колонки переходят в последовательную компоновку.
- Добавлены декоративные SVG-цветы. Отзывы, клиентские кейсы, метрики и контакты не выдумывались. Форма только копирует текст.

## Проверки

Playwright / Chromium, локальный HTTP-сервер:

- 360, 390, 768, 1440 px: сняты скриншоты, проверена композиция. Ширина документа равна ширине viewport на всех четырёх размерах.
- На каждой ширине открыты все три демо. Проверены действия внутри, Escape из iframe и возврат фокуса на соответствующее превью.
- Проверено копирование заявки, сброс статуса при редактировании, ссылка пропуска содержимого с Tab/Enter.
- При reduced motion scroll-behavior равен auto.
- Все изображения загружаются. Ошибок в консоли нет.
- node --check dist/app.js проходит. Проверены уникальные ID, внутренние ссылки и локальные ресурсы HTML.

Проверки в других браузерах, на физических устройствах и измерение FPS не выполнялись. Изменения не опубликованы.

Просмотр: http://127.0.0.1:8000 . Обновление без кеша: Ctrl + Shift + R.

## Расширение и скругления

По следующему запросу увеличена максимальная ширина страницы до 1760 px. При viewport 1440 px блоки имеют ширину 1376 px, поля — по 32 px вместо 130 px. При 1920 px ширина блоков 1760 px.

Добавлена иерархия радиусов: 26 px для крупных бордов, 18 px для парных панелей, 8–12 px для деталей и превью. Увеличены пояснения, поля формы и скриншоты. Добавлена круглая типографическая печать Mindfind по мотивам референса; уточнены градиенты и контуры лепестков. Исправлена тесная компоновка описания обновления сайта и полей формы на планшетах.

Повторно пройдены 360/390/768/1440/1920 px: горизонтального переполнения нет; три демо на каждой ширине открываются, действия внутри работают, Escape возвращает фокус на превью. Копирование формы работает, изображения загружаются, в консоли ошибок нет. Скриншоты просмотрены, node --check проходит. Публикации не было.
