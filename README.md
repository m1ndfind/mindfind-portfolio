## Локально
```bash
python3 -m http.server 8000 --directory dist --bind 127.0.0.1
```
Откройте http://127.0.0.1:8000 . Сборка не нужна.

## Продолжить в Codex
```bash
git init
git add .
git commit -m "Import Mindfind portfolio"
codex
```
Первое сообщение: «Прочитай AGENTS.md. Запусти сайт, проведи визуальную проверку на компьютере и телефоне, исправь наложения и читаемость. Сохрани палитру, персонажа и бейдж. Не публикуй без настроенного доступа».

Скиллы и MCP устанавливаются отдельно в вашем Codex; архив не содержит их установок. Экспорт актуальных исходников, а не Git-история.
