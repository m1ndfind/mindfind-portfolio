# Mindfind® · Cinematic Scroll Portfolio

Статическое портфолио на русском языке. Сборка и просмотр работают локально. Нужны Node.js 20+ и Python 3.

```sh
npm run build
npm run preview
```

Локальный адрес — http://127.0.0.1:8000/. После изменения исходников повторите сборку. Для статического хостинга используется содержимое `dist/`.

## Устройство проекта

- `src/index.html`, `src/styles.css` задают разметку, бумажные поверхности, слои сцены, типографику и адаптивную компоновку.
- `src/main.js` подключает модули. `src/intro.js` связывает пролёт камеры, заголовок, портрет и проявление манифеста с одним положением прокрутки.
- `src/chrome.js` формирует сетку ленты и шейдеры. `src/scenes.js` рисует хром в Hero, обрабатывает потерю и восстановление WebGL-контекста, ограничивает размер буфера и приостанавливает рендер вне видимой области.
- `src/motion.js` подключает сцены по видимости и обрабатывает указатель. `src/choreography.js` использует Web Animations API для входов, CSS scroll timeline — для индикатора чтения в поддерживающих браузерах.
- `src/work-scroll.js` переводит три карточки из ряда в список, синхронизирует окно Leaf Studio, фильм Mono Coffee и переход в Form Digital. Подтверждение от вложенного Leaf разрешает показать его вместо скриншота.
- `src/interactions.js` управляет диалогом, форматом устройства, возвратом фокуса и локальным копированием брифа.
- `public/assets/` содержит оригинального персонажа, бейдж, WebP-кадры скульптур, превью и фильм. `public/demos/` содержит три самостоятельных учебных концепта.
- `scripts/build.mjs` формирует `dist/` из `src/` и `public/`. Сборка работает без установки зависимостей.

При отключённом JavaScript проекты открываются по обычным ссылкам. Для копирования брифа требуется JavaScript. При запрете Clipboard API доступно выделенное поле с текстом. Адрес получателя пока не задан.

В режиме сокращённого движения и в коротком окне витрина становится списком. В режиме сокращённого движения скульптура сохраняет выбранный ракурс. При отсутствии WebGL отображаются локальные кадры. Фильм используется только для проекта Mono Coffee.

## Студия автора

После работ расположен `#mindfind-story`. Разметка глав находится в `src/index.html`, оформление в `src/studio.css`, единый контроллер прокрутки и компактное меню в `src/studio.js`. Поля брифа остаются в потоке после главы 05.

`src/avatar.js` рисует студию с объёмным подиумом, сиденьем и фигурой из авторской иллюстрации. Локальные модули Three.js 0.187.0 и GLTFLoader лежат в `public/vendor/` вместе с лицензией MIT. На небольших экранах, программном рендерере и при недоступности WebGL используются 31 локальный WebP-кадр той же камеры и ограниченный кэш в `src/avatar-sequence.js`. При сокращённом движении видна статичная иллюстрация.

Чтобы подключить готового двойника, поместите самодостаточный GLB в `public/assets/` и укажите его относительный URL в `data-model` у `.studio-art`. Перед модели направлен по +Z. Загрузчик нормализует высоту и положение ног, а клип с именем Idle запускается независимо от камеры. Для точного сходства потребуются фотографии анфас, в три четверти, профиль и полный рост в нужной одежде.
