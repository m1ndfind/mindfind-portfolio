# Mindfind — портфолио веб-разработчика

## Проект
Статический сайт на HTML, CSS и vanilla JavaScript. Нет сборки и зависимостей npm. Основной файл dist/index.html (CSS внутри), поведение dist/app.js. В dist/assets два PNG персонажа; dist/demos — три самостоятельных интерактивных концепта. dist/spatial.js — старый, сейчас не подключённый код, не подключать без проверки.

## Владелец и требования
Псевдоним Mindfind. Общение по-русски, прямо, без воды. Нужен законченный проверенный результат. Сохранить тёмную палитру с шалфейным акцентом, основного персонажа и бейдж с портретом. Одежду персонажа не менять. Никаких эмодзи вместо иконок, использовать SVG. Понятные кнопки, читаемые пояснения, нормальные межбуквенные интервалы, отсутствие наложений. Обычный скролл между секциями. Не превращать страницу в бесконечную сетку карточек. Не добавлять плавающий маскот и дёрганые движения, скрытие всего содержимого до анимации. Анимации — только обоснованные, с prefers-reduced-motion. Не переделывать весь дизайн без нового запроса.

## Текущее состояние и проблемы
Последний экспорт — commit 7d737f590a3bad548d786960a5b2926010e6f2f8. После розово-бордового эксперимента возвращены тёмные цвета, основной персонаж, бейдж, увеличены пояснения и исправлен трекинг заголовков. Последняя версия НЕ проверена визуально в браузере. Не заявлять, что все баги устранены. CSS накопил переопределения — сначала проверить computed styles, затем осторожно упорядочивать.
Проверить первый экран, размер и обрезание персонажа, вложенность и размеры бейджа, заголовки, промежутки, переносы навигации, переполнение на узких экранах. Проверить 360/390/768/1440 px, проектный переключатель, iframe, диалог, Escape и клавиатуру. Убедиться, что нет горизонтального скролла и наложений. FPS не измерялся.
Демо Leaf Studio, Mono Coffee, Form Digital — учебные концепты, не реальные клиентские кейсы. Не придумывать метрики и отзывы.
Контакт владельца не указан: форма только копирует заявку в буфер, ничего не отправляет и не сохраняет. Не выдавать её за рабочую отправку. Для отправки нужен настоящий контакт или backend.
Друг сообщил о блокировке с ПК. Причина неизвестна; ранее сайт открывался публично, ошибка не воспроизведена.

## Запуск
Из корня проекта:
```bash
python3 -m http.server 8000 --directory dist --bind 127.0.0.1
```
Открыть http://127.0.0.1:8000 . Остановить Ctrl+C. Не открывать через file://.
Проверка синтаксиса:
```bash
node --check dist/app.js
```
Браузерные проверки выполнять через доступный Playwright/MCP. Не писать, что проверено, если инструменты недоступны.

## Публикация и безопасность
Действующий URL: https://mindfind-web-portfolio.affectionateapple3.chatgpt.site
.openai/hosting.json содержит публичный идентификатор существующего Site, не пароль. Экспорт не содержит авторизации, Git remote или истории. Локальные изменения автоматически не публикуются. Для публикации на прежний Site нужен авторизованный Sites workflow; либо отдельно настроенный пользователем хостинг. Не создавать другой Site случайно и не обещать автоматическое обновление старого URL. Никогда не сохранять токены в файлах и Git.
