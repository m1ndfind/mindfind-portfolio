# Mindfind® Portfolio

Статическое портфолио на HTML, CSS, ES modules и нативном WebGL. Правки вносить в `src/` или `public/`. `npm run build` заново формирует `dist/`, `npm run preview` открывает локальный HTTP-сервер на 127.0.0.1:8000. Сборка не требует сети или npm-зависимостей.

## Бренд и контент

- Общаться с владельцем по-русски. Текущая арт-дирекция использует бумажный фон, чёрную наборную типографику, красный акцент и хром.
- Сохранять бренд Mindfind, внешность и одежду оригинального персонажа и компактный бейдж с портретом. Оригинальные изображения находятся в `public/assets/`. В интерфейсе используются локальные WebP-копии.
- Leaf Studio, Mono Coffee и Form Digital — учебные концепты. Сохранять их интерактивные макеты и обозначение статуса. Клиентские отзывы, достижения и контакты должны опираться на реальные данные.
- Форма подготавливает и копирует текст в буфер. Ручное копирование доступно, если Clipboard API отклонил запрос.

## Проверки

Перед сдачей собрать сайт и проверить 360, 390, 768, 1024, 1440 и 1920 px. Проверять клавиатурную навигацию, фокус, Escape из диалога и iframe, копирование с доступным и недоступным Clipboard API, сокращённое движение и статичный режим без WebGL. Останавливать рендер вне экрана и при скрытии вкладки. При изменении геометрии или шейдеров обновлять статичные кадры в `public/assets/`.

Работать в отдельной ветке. Для обновления публичного сайта требуется отдельное разрешение владельца. Идентификатор существующего сайта и путь к сборке находятся в `.openai/hosting.json`.

## Кинематографическая версия

Проверять также 320, 430, 820, 1280 px и низкое окно в landscape. Готовность превью Leaf подтверждает сообщение из его sandboxed iframe. Проверять ошибку загрузки демо и фильма с сохранением статичного изображения. Критические стили и движение должны работать с локальными ресурсами. При изменении камеры сохранять исходную позу при нулевом прогрессе для совпадения с постером.
