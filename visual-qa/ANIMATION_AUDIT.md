# Анимация персонажа
GLB содержит клип Idle с десятью каналами. В браузерном тесте камера зафиксирована в (0, 1.65, 5.5), направление взгляда одинаково во всех кадрах. Тест снимает локальные quaternion непосредственно перед renderer.render. У Head, Chest, ShoulderL/R, ElbowL/R и HandL значения изменились после двух секунд работы микшера при неизменном прогрессе. При одинаковом времени клипа положение ElbowL также различается между второй и третьей главами. WebGL вернул NO_ERROR. Цифры и шесть кадров находятся в videos/.

Движение витрины проверено в Chromium. При остановленной прокрутке CSS translate у дорожки изменился за 500 мс. Ряды повторяют группу из трёх работ и проходят целое число плиток за цикл. Последовательность videos/story-00…10 показывает прокрутку трёх глав вперёд и обратно. Кадры site-hover-* и site-keyboard-focus фиксируют состояние галереи. Открытие диалогов проверено для каждого проекта и формата просмотра. Динамическая смена настройки reduced motion прошла в обе стороны.

Прогресс реального WebGL Hero при семи последовательных позициях скролла вырос с 0,014 до 0,987. Кадры videos/qa-hero-motion-* просмотрены. Проверка sticky-карточек подтвердила удержание трёх рамок внутри окна 1440×900. Результаты наведения и клавиатурного фокуса сохранены в screenshots. Для программной отрисовки заменено повторное копирование битмапа в canvas на композицию декодированных изображений. При неподвижной прокрутке виден один кадр.
